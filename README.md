# 🌿 TerraQuest AI

### Stop Scrolling. Start Exploring.

TerraQuest AI is an AI-powered outdoor adventure generator
that encourages people to spend less time on screens
and more time exploring the real world.

## Features

- AI-generated outdoor adventures
- Personalized missions
- Touch Grass Mode
- Adventure completion tracking
- Achievement badges
- Local AI inference

## Tech Stack

- Python
- Streamlit
- Ollama
- Qwen2.5 1.5B

## How to Run

1. Install Python and Ollama.
2. Download the model:
   ollama pull qwen2.5:1.5b
3. Install dependencies:
   pip install -r requirements.txt
4. Start the application:
   streamlit run app.py

Ollama must be running locally.

## Why Open-Weight AI?

TerraQuest AI uses a locally running open-weight model
to generate personalized outdoor activities.

This reduces dependence on paid AI APIs
and gives developers more control over their AI applications.
